# Conway's Game of Life

Реализация классической игры «Жизнь» Джона Конвея на Go с графическим интерфейсом.

## Управление

| Действие | Клавиша |
|----------|---------|
| Пауза / Запуск | `Space` |
| Случайное заполнение | `R` |
| Очистка поля | `C` |
| Выход | `Esc` |
| Скорость 1x | `1` |
| Скорость 2x | `2` |
| Скорость 4x | `3` |
| Скорость 8x | `4` |
| Скорость 16x | `5` |
| Скорость 32x | `6` |
| Скорость 64x | `7` |

**Мышь:**
- ЛКМ — создать клетку
- ПКМ — удалить клетку

## Сборка

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/game-of-life.git
cd game-of-life
```

# Запуск
go run main.go

# Компиляция в .exe
go build -ldflags="-s -w" -o gameoflife.exe main.go

## Особенности
- Поле 60×35 клеток
- Скорость симуляции от 1x до 64x
- Границы поля — мёртвая зона (классические правила)
- Нижняя панель с информацией и управлением

## Зависимости
```bash
[raylib-go](https://github.com/gen2brain/raylib-go) — графическая библиотека

go get github.com/gen2brain/raylib-go/raylib
```

## Правила игры
1. Живая клетка с 2-3 живыми соседями выживает
2. Мёртвая клетка с 3 живыми соседями рождается
3. В остальных случаях клетка умирает или остаётся мёртвой
